# AlgoritmoEscalable (/docs/camara/v1/referencia/algoritmo-escalable)



`AlgoritmoEscalable` implementa la estrategia `DifuminadoEscalable` utilizada por `Camara`. El árbol de clases incluye también los tipos de comparación y configuración que necesita el algoritmo. fileciteturn418file0

Su responsabilidad es producir la textura auxiliar que representa la región de escena procesada para el difuminado. La selección del algoritmo se realiza mediante `Camara.Algoritmo` y la configuración se inyecta mediante `Camara.ConfiguracionDifuminado`.
