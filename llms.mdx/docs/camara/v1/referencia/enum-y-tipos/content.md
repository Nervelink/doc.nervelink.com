# Enums y tipos (/docs/camara/v1/referencia/enum-y-tipos)



El módulo mantiene sus enums separados de las clases de comportamiento. Entre los tipos presentes están:

| Tipo                  | Propósito                                             |
| --------------------- | ----------------------------------------------------- |
| `AlgoritmoDifuminado` | Estrategia de difuminado                              |
| `DatosAuxiliares`     | Datos auxiliares de cálculo                           |
| `EjesCamara`          | Ejes utilizados por la cámara                         |
| `EstadoBtn`           | Estado de controles asociados                         |
| `EstadoCamara`        | Estado lógico de la cámara                            |
| `TipoAlgoritmoCamara` | Clasificación del algoritmo de cámara                 |
| `TipoEntrada`         | Tipo de entrada utilizado por herramientas del módulo |
