# Glosario (/docs/red/v1/ingenieria/glosario)



## Eco [#eco]

Capa principal de gestión y acceso a la red.

## Objeto [#objeto]

Entidad de red con identidad propia dentro de un canal.

## Componente [#componente]

Unidad modular asociada a un objeto para encapsular estado o comportamiento.

## Canal [#canal]

Ámbito lógico de participación y sincronización.

## Jugador [#jugador]

Identidad de un participante conectado a la sesión.

## Objetivo [#objetivo]

Destino o conjunto de destinos de una comunicación.

## RFC [#rfc]

Llamada remota utilizada para solicitar o ejecutar una acción distribuida.

## Ownership [#ownership]

Relación de control de red de un objeto.

## Autoridad [#autoridad]

Entidad que puede determinar el estado válido de una regla de gameplay.

## Persistencia [#persistencia]

Estado que puede sobrevivir al ciclo de vida inmediato de un objeto o sesión.

## Paquete [#paquete]

Unidad estructurada del protocolo de comunicación.

## Buffer [#buffer]

Representación binaria utilizada para leer y escribir datos transportados por el protocolo.

## Serialización [#serialización]

Conversión entre estructuras de runtime y una representación transmisible o persistible.
