# Persistencia [#persistencia]

La persistencia de Eco no es el guardado de partida del gameplay. Es la capacidad del servidor para conservar suficiente estado de red como para restaurar canales, objetos, datos y RFC cuando el proceso o los jugadores cambian de estado.
