## Dependencias [#dependencias]

El paquete `com.pandora.modulo.misiones` **1.0.1.1** declara una dependencia explícita de `com.pandora.modulo.motor` **1.1.4.0**. fileciteturn451file0

## Rutas [#rutas]

El manifiesto reserva estas rutas:

```text
Assets/Pandora/Logica/Misiones/
Assets/Pandora/Datos/Misiones/
```

La clase `DatosMisiones` utiliza además `Assets/Pandora/Datos/Misiones/Resources` como ruta de datos predeterminados en el editor y `Resources/Datos/DatosMisiones` como ruta de carga en ejecución. fileciteturn451file0 fileciteturn453file0

## Limitaciones actuales [#limitaciones-actuales]

El repositorio disponible no contiene todavía un sistema runtime completo de misión, un editor de grafos de misiones ni clases públicas para objetivos, estados, ramas o recompensas. El manifiesto describe esas capacidades como objetivo funcional, pero no deben considerarse API actual. fileciteturn451file0 fileciteturn456file0
