# Instalar el módulo (/docs/misiones/v1/guias/instalar-modulo)



El manifiesto del paquete identifica `Pandora.Motor` como dependencia. La instalación debe realizarse mediante el flujo habitual de paquetes de Pandora Crystal o integrando el repositorio en el proyecto. fileciteturn451file0

<Steps>
  <Step>
    Instala el módulo 

    `p.m.misiones`

     y su dependencia 

    `Motor`

    .
  </Step>

  <Step>
    Comprueba que el paquete quede bajo las rutas 

    `Assets/Pandora/Logica/Misiones/`

     y 

    `Assets/Pandora/Datos/Misiones/`

    .
  </Step>

  <Step>
    Verifica que exista el recurso de datos de misiones antes de intentar cargar 

    `DatosMisiones.I`

    .
  </Step>
</Steps>
